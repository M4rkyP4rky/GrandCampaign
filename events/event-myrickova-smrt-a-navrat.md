# Myrick's death and return through Smrt

## Description and outcome

Myrick dies from his wounds in the marsh branch and encounters Smrt while looking down on his own body. The encounter returns him to continuing action rather than creating a second Myrick identity.

Outcome: Myrick returns from death and continues as the same being.
