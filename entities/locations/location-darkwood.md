# Darkwood

## Description

Yann uses `Darkwood` for Ruthwen's panství and describes a residence there with underground areas, towers, servants, and prisoners. The source does not clearly separate the named domain from its principal residence, so this record preserves the location identity without asserting exact extent or a physical hierarchy.
