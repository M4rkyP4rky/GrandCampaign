# Assets

Store repository-owned maps, illustrations, sketches, and other images here:

- `maps/` for maps;
- `images/` for general illustrations and images;
- `sketches/` for sketches and working visual references.

Use descriptive ASCII filenames where practical, avoid overwriting a materially different asset, and link from Markdown with ordinary relative paths, for example `![description](../../assets/maps/<filename>.png)` adjusted for the record's location.

Do not add placeholder images, coordinates, GIS data, or generated spatial systems. Git LFS is not configured; reconsider large-file handling only when real repository needs justify it.
