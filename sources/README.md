# Sources

This directory holds preserved raw material from which archive records may later be derived.

- `inbox/`: newly received material awaiting review and classification.
- `campaigns/`: raw material grouped by campaign after a campaign convention is approved.
- `shared/`: raw material that is not specific to one campaign.

Raw sources are evidence. Never silently rewrite them to normalize spelling, resolve contradictions, or match derived records. Put interpretation and corrections in derived records with explicit provenance, leaving the original source intact.

Use portable, repository-contained formats where practical. Do not ingest campaign content until the schema has been reviewed and an ingestion task explicitly authorizes it.
